# 组件说明

页面通过 Astro 组合静态内容，Svelte island 提供交互；所有组件沿用现有主题变量。

| 目录 | 职责 |
| --- | --- |
| `common/` | 图片、Markdown、按钮、下拉容器与分页 |
| `layout/` | 导航、侧栏、页脚、文章卡片和元信息 |
| `controls/` | 搜索、主题、显示设置、目录和返回按钮 |
| `features/` | 当前樱花、打字机、图片查看、字体、数学公式和文章加密 |
| `about/` | d3-cloud 标签词云适配，含文本链接降级 |
| `other/` | 妙妙屋工具卡片与懒加载 Shell，乐器实现位于 `src/features/other/stylophone/` |
| `widget/` | 个人资料、公告、分类、标签、统计和阅读目录 |
| `misc/` | 许可声明、相关文章与分享海报 |
| `pages/` | 高级搜索 |

已清理音乐播放器、评论、分析、广告与日历。触笔电子琴基础版已实现，音频由独立模块管理，不恢复全局音乐播放器；季节场景待实施。

## 约束

- 先复用第三方库和仓库组件，不自写粒子、词云或音频调度引擎。
- 非首屏增强按需加载；浏览器 API 只能在客户端执行。
- Swup 页面切换后须正确初始化和销毁；清理监听、observer、计时器和库实例。
- 站内链接经过 url-utils，兼容 `/blog/`。
- 复杂模块按页面、UI、数据、输入与资源管理拆分，不向全局 Layout 注入玩具运行时。

详细约束见根目录 [AGENTS.md](../../AGENTS.md)，演进方案见 [执行计划](../../docs/plans/)。
