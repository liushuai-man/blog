# 街边小卖部：场景规范与素材生成提示词

版本：v1.0 · 更新：2026-10-14 · 状态：规范与提示词已编写，尚未生成素材。

用户已指定的场景与视角：**一个街边的小卖部，两边有树木绿化，视角正对小卖部**。下方画风、店面细节和构图是本版的执行默认值，不视为用户额外指定。后续调整先修改本规范；同一版素材不得自行换场景或画风。

本文件是场景美术的唯一规范，配合 [执行计划一](../plans/01-seasonal-scenes.md) 使用。生成静态素材，动画由开源组件驱动；不将生图工具当作动画、Lottie 文件或可编辑图层的生成器。

## 1. 场景固定内容

场景名称：`corner-shop`，中国普通居民区的一家单层街边小卖部。气质安静、亲切，像每天经过的熟悉小店。

| 要素 | 固定规则 |
| --- | --- |
| 镜头 | 正对小卖部门面中心，平视，镜头方向垂直于门面；门面与画面平行，门框竖直、屋檐水平；不使用侧视、斜视、三分之四视角、俯视、仰视、鱼眼或夸张透视 |
| 店铺 | 单层、浅米白墙面、浅灰平屋顶，低饱和灰绿色短遮阳棚 |
| 门窗 | 正面左侧一扇展示窗，右侧一扇玻璃门；数量、比例与位置不变 |
| 招牌 | 遮阳棚上方一块素色矩形招牌；留白，文字后续单独叠加 |
| 店内 | 玻璃后有简化货架与零食轮廓，不出现可识别商品品牌或包装文字 |
| 树木 | 左侧一棵樱花树，右侧一棵落叶阔叶树，共两棵；树干、分叉和根部位置固定 |
| 绿化 | 两侧低矮灌木／草带，保持相同边界，不遮挡门窗 |
| 街道 | 店前窄人行道与路缘，前景一段水平道路；无巨大路口或复杂交通设施 |
| 背景 | 简化的居民区低矮轮廓与干净天空，避免大量高楼或远景地标 |
| 活动主体 | 第一版不添加人物、车辆、动物；后续新增必须单独更新规范 |

每次变化都应让人辨认出同一家店、同两棵树、同一段街道。店铺不变成咖啡馆、日式便利店、庭院、窗边书桌或森林小屋。

## 2. 画风与构图

统一采用柔和二维数字插画：简洁形状、细腻但克制的手绘纹理、轻微轮廓线、低饱和色彩。避免照片质感、像素风、黏土／玩具 3D、厚重油画、高饱和霓虹和过量细节。

基础配色参考：墙面 `#E8E1D2`，遮阳棚 `#7E998D`，路面 `#9EA7A3`。这些值用于方向参考，实际颜色以验收后的母版为准，不要求模型逐像素执行十六进制值。

### 桌面构图

目标比例 **7:3**，目标画布 **2520 × 1080**。左上角为坐标原点，百分比相对于整张图：

- 店铺居中，主体范围约 x=34%–66%、y=38%–76%。
- 左树干根部约 (18%, 77%)，右树干根部约 (82%, 77%)。
- 两侧树冠主要占据左右各约 25% 的区域，不能横跨整个中央天空。
- 人行道约 y=76%–84%，道路约 y=84%–100%。
- 中央 x=30%–70%、y=8%–30% 是标题留白区，保持低细节、无树枝穿过。
- 外缘保留约 5% 安全边距，不在边缘放必须完整保留的细节。

坐标是生成和验收的目标，不是生图工具保证。第一张通过验收后，实际轮廓与位置即成为所有派生素材的参照。

### 移动构图

目标比例 **3:2**，目标画布 **1200 × 800**，继续采用横向街景。店铺约 x=27%–73%、y=38%–78%；左右树干根部约 (12%, 79%)、(88%, 79%)；中央上方保留标题空间。

移动版基于桌面母版做一次明确的构图适配，保留同一家店与同两棵树；之后移动版也锁定自身镜头。不要把超宽图直接裁成竖图而只留下店门，也不要为手机另画一个不同场景。

最终尺寸、实际横幅高度和裁切方式必须在接入时一起验证。不能通过拉伸图片或任意 object-position 掩盖构图不合格。

## 3. 允许变化的内容

| 状态 | 允许改变 | 必须保持 |
| --- | --- | --- |
| 春 | 左树淡粉花簇，右树嫩绿叶片，两侧草带鲜嫩 | 店铺、树干和树枝骨架、镜头 |
| 夏 | 左右树冠浓绿，绿化更茂盛但边界不扩张 | 同上 |
| 秋 | 左树叶片暖褐，右树金黄／橙褐，地面少量静态落叶 | 同上 |
| 冬 | 树冠稀疏，露出原树枝，屋顶／树枝／草带少量静态积雪 | 同上 |
| 昼夜 | 天空、光照、阴影强度；夜间店内微暖灯光 | 建筑结构、商品轮廓、植物位置和季节 |
| 晴 | 轻柔晴天光照 | 季节植被与构图 |
| 雨 | 环境光稍冷、路面轻微湿润；动态雨丝由运行时叠加 | 季节植被，不出现雷暴、洪水 |
| 霜 | 窗框／路缘／枝条附着薄霜 | 不是满地积雪，不改变季节树冠 |
| 雪 | 动态稀疏雪花由运行时叠加 | 除冬季底图外，不自动将其他季节改成冬季 |

春夏秋冬与霜雨晴雪独立组合。春季小雨仍是春景；夏季选择雪也保留夏季底图。第一版不自动将天气与真实定位或天气服务关联。

底图不画正在飘落的花瓣、雨丝、飞雪或萤火虫；冬季静态积雪与运行时雪花是两回事。所有效果暂停后仍是一幅完整街景。

## 4. 生成顺序与参考图角色

1. 用 P01 生成桌面“春季／白天／晴天”母版，按本文件验收。
2. 通过验收的图登记为 `desktop-master-v1`。不合格时只修正具体问题，不批量生成其他状态。
3. 用 P02 和已验收桌面母版生成移动母版，登记为 `mobile-master-v1`。
4. 每个端的夏、秋、冬都直接编辑该端的春季母版，不采用“春→夏→秋→冬”的连续重绘，避免累计漂移。
5. 每个季节的夜景直接编辑该季节的已验收白天图；不能拿春夜当夏夜的唯一参照。
6. 天气附着层、粒子素材最后生成，尺寸和风格来自已经锁定的母版。

每次调用明确标注输入：**图 1 = 编辑目标**；如需另一张图约束造型，标注 **图 2 = 结构参考**，不要把不同季节都称为同等风格参考。

母版图一旦换版，所有派生图重新验收。不允许用生成后未验收的图覆盖母版路径。提示词能减少漂移，不能代替参考图编辑和逐张验收。

## 5. 可直接使用的提示词

### P01：首次生成桌面母版

```text
用途：个人技术博客横幅的静态场景母版，柔和二维数字插画。
生成一幅中国普通居民区的街边小卖部场景：一家单层小店位于画面中央，店铺两侧分别有一棵树和低矮绿化。左侧是一棵樱花树，右侧是一棵落叶阔叶树。
店铺固定设计：浅米白墙面，浅灰平屋顶，低饱和灰绿色短遮阳棚；正面左侧一扇展示窗，右侧一扇玻璃门，遮阳棚上方一块留白的素色矩形招牌。玻璃后有简化货架与零食轮廓，不出现可识别品牌或包装文字。
镜头正对小卖部门面中心，平视，视线垂直于门面，门面与画面平行；门框竖直，屋檐和招牌水平。采用正面立面式插画构图，不画侧墙，不使用斜视、三分之四视角、俯视、仰视或夸张透视。宽高比 7:3，目标 2520×1080。店铺约占 x34%–66%、y38%–76%；左右树干根部约在 x18% 和 x82%、y77%。树冠主要在两边，不遮住门窗。
店前有窄人行道和路缘，底部是安静的水平道路。远处只有低细节居民区轮廓与天空。中央上方 x30%–70%、y8%–30% 保持干净柔和，供网页后期叠加标题；图中不生成任何标题文字。
时间为春季白天晴天：左树有克制的淡粉花簇，右树有嫩绿叶片，草带清新。光照柔和，自然清爽，阴影轻，不刺眼。
画风为简洁形状、轻微轮廓线、克制手绘纹理的二维插画。配色低饱和、统一、温暖亲切；米白、灰绿、嫩绿和少量淡粉为主。
输出一张完整静态场景，不是拼图、分镜、素材合集或网页截图。不画人物、汽车、动物、Logo、水印、可读招牌文字、霓虹、散落雨丝、飘落花瓣、飞雪或发光粒子。不改变为咖啡馆、庭院、森林小屋，不使用写实摄影或 3D 质感。
```

## 7. 验收与禁止事项

- [ ] 镜头正对小卖部，门面与画面平行，门框竖直、屋檐水平，没有侧墙主导或斜向透视。
- [ ] 与母版并排或半透明叠加检查：店铺边界、门窗、遮阳棚、树根、主要树干、路缘未漂移。
- [ ] 非季节几何锚点偏移超过画布宽／高约 1%，或肉眼可见结构改变时修正；不靠裁切补救。树叶密度变化不作为树干漂移。
- [ ] 四季配色与植物变化明确，当前天气没有偷偷改变季节。
- [ ] 标题区域干净，无生成文字、商标、水印或新主体。
- [ ] 透明层有真实 alpha，位置对齐，边缘没有白边；不能把截图里的棋盘格当透明。
- [ ] 在实际横幅、375px／768px／1440px、深浅主题下确认店铺与两侧绿化可辨认，标题清晰。
- [ ] 停止所有动画后仍完整美观；底图没有烘焙飘落粒子。
- [ ] 所有运行时素材有清单与对应提示词，未验收素材不标记为 ready。

同版本禁止随机改招牌、门窗数量、树木数量、房屋风格、镜头透视或画风。不要并行盲生成整套图片，不依赖相同提示词／随机 seed 保证结构一致，不承诺生成器能像设计软件那样精确锁定图层和坐标。
