# 居民区两层小卖部：场景规范与素材生成提示词

版本：v2.0 · 更新：2026-10-14 · 状态：按用户反馈修订规范；生成图仍为预览候选，尚未锁定母版。

用户已指定的场景与视角：**小省城居民区的一处两层小卖部，正面视角；一楼有门和开放式售货窗口，二楼居住；背景是高白墙、黑铁栏与攀爬植物，两侧粗老树干，地面为公园步道砖；整体紧凑、有生活气息**。下方画风、店面细节和构图是本版的执行默认值，不视为用户额外指定。后续调整先修改本规范；同一版素材不得自行换场景或画风。

本文件是场景美术的唯一规范，配合 [执行计划一](../plans/01-seasonal-scenes.md) 使用。生成静态素材，动画由开源组件驱动；不将生图工具当作动画、Lottie 文件或可编辑图层的生成器。

## 1. 场景固定内容

场景名称仍为 `corner-shop`（稳定资源标识，不再表示必须位于街边）。地点是中国小省城的老居民区，一楼售货、二楼居住的两层小卖部。

| 要素 | 固定规则 |
| --- | --- |
| 镜头 | 正对建筑正面，平视，门面与画面平行；门框竖直、楼层水平，不侧视、斜视、俯视或仰视 |
| 建筑 | 完整两层，上下同一栋居民自住房；墙面有轻微旧痕和修补，不是单层商业店面 |
| 一楼 | 左侧开放式售货窗口，右侧一扇普通住户式门；售货窗无固定玻璃阻隔，窗台可递交货物 |
| 售货窗口 | 内侧密集小货架与日用品，窗边有零食、瓶罐、篮筐；保留清晰窗口与交易台面，不做大型玻璃橱窗 |
| 二楼 | 明确有人居住：两扇普通住宅窗，窗帘、少量晾晒衣物、窗边盆栽；不是第二层商业空间 |
| 招牌 | 一楼上方小而朴素的留白招牌；不使用大型连锁商店灯箱和整面商业雨棚 |
| 生活细节 | 门边小板凳、周转箱、旧花盆和少量管线，紧凑但不脏乱；第一张确认后位置锁定 |
| 背景 | 建筑背后和两侧可见较高白墙，墙顶黑色铁栏，铁栏缠绕藤蔓与灌丛；没有开阔远景居民区步道和大片现代楼群 |
| 树木 | 左右各一棵粗大古老的树，粗糙树皮、明显根部和大分叉；固定树干骨架，树冠可在顶部合拢形成盖顶 |
| 绿化 | 树根附近与围墙边紧凑的灌木、草和盆栽；不画成整齐宽阔的商业景观带 |
| 地面 | 灰褐色公园步道砖，错缝铺装、细砖缝与少量岁月痕迹；没有沥青车道和公路标线 |
| 活动主体 | 本版通过居住与售货细节表达生活气息，暂不添加人物、车辆或动物 |

每次变化都应辨认出同一栋两层住宅小卖部、开放式售货窗、同两棵古树与围墙。不得变成现代商店、咖啡馆、日式便利店或孤立景观小屋。

## 2. 画风与构图

统一采用柔和二维数字插画：简洁形状、细腻但克制的手绘纹理、轻微轮廓线、低饱和色彩。避免照片质感、像素风、黏土／玩具 3D、厚重油画、高饱和霓虹；允许适度密集的生活细节，避免空旷、过度整洁的商业效果图。

基础配色参考：住宅墙面旧米白 `#E8E1D2`，背景围墙偏白，黑铁栏深灰，步道砖灰褐 `#9EA29B`。这些值用于方向参考，实际颜色以验收后的母版为准，不要求模型逐像素执行十六进制值。

### 桌面构图

目标比例 **7:3**，目标画布 **2520 × 1080**。左上角为坐标原点，百分比相对于整张图：

- 两层建筑居中，主体约 x=33%–67%、y=18%–80%，两层均完整可见。
- 左右粗老树干根部约在 (15%, 83%)、(85%, 83%)，树干不能被细小新树替代。
- 树冠从左右向上延展，可在顶部形成覆盖感；保持二楼窗与一楼门、售货窗清晰可辨。
- 白墙与黑铁栏紧邻建筑后方，占据两侧中景，藤蔓自然缠绕铁栏。
- 步道砖约占底部 y=80%–100%；建筑、植物与生活小物之间间隙较小。
- 不强求大片天空留白；标题接入时单独选择低细节区和遮罩，不为标题把建筑压成单层。
- 边缘允许树冠自然出画，但树干、门、售货窗与二楼住宅窗不能被裁掉。

坐标是生成和验收的目标，不是生图工具保证。第一张通过验收后，实际轮廓与位置即成为所有派生素材的参照。

### 移动构图

目标比例 **3:2**，目标画布 **1200 × 800**，继续采用居民区正面场景。建筑约 x=25%–75%、y=15%–82%；左右树干根部约 (10%, 84%)、(90%, 84%)。两层均须可见，顶部树冠可覆盖，不强求天空留白。

移动版基于桌面母版做一次明确的构图适配，保留同一家店与同两棵树；之后移动版也锁定自身镜头。不要把超宽图直接裁成竖图而只留下店门，也不要为手机另画一个不同场景。

最终尺寸、实际横幅高度和裁切方式必须在接入时一起验证。不能通过拉伸图片或任意 object-position 掩盖构图不合格。

## 3. 允许变化的内容

| 状态 | 允许改变 | 必须保持 |
| --- | --- | --- |
| 春 | 左树淡粉花簇，右树嫩绿叶片，两侧草带鲜嫩 | 店铺、树干和树枝骨架、镜头 |
| 夏 | 左右树冠浓绿，绿化更茂盛但边界不扩张 | 同上 |
| 秋 | 左树叶片暖褐，右树金黄／橙褐，地面少量静态落叶 | 同上 |
| 冬 | 树冠稀疏，露出原树枝，屋顶／树枝／草带少量静态积雪 | 同上 |
| 昼夜 | 天空、光照、阴影强度；夜间店内微暖灯光 | 建筑结构、商品轮廓、植物位置和季节 |
| 晴 | 轻柔晴天光照 | 季节植被与构图 |
| 雨 | 环境光稍冷、路面轻微湿润；动态雨丝由运行时叠加 | 季节植被，不出现雷暴、洪水 |
| 霜 | 窗框／步道边缘／枝条附着薄霜 | 不是满地积雪，不改变季节树冠 |
| 雪 | 动态稀疏雪花由运行时叠加 | 除冬季底图外，不自动将其他季节改成冬季 |

春夏秋冬与霜雨晴雪独立组合。春季小雨仍是春景；夏季选择雪也保留夏季底图。第一版不自动将天气与真实定位或天气服务关联。

底图不画正在飘落的花瓣、雨丝、飞雪或萤火虫；冬季静态积雪与运行时雪花是两回事。所有效果暂停后仍是一幅完整居民区场景。

## 4. 生成顺序与参考图角色

1. 用 P01 生成桌面“春季／白天／晴天”母版，按本文件验收。
2. 通过验收的图登记为 `desktop-master-v2`。不合格时只修正具体问题，不批量生成其他状态。
3. 用 P02 和已验收桌面母版生成移动母版，登记为 `mobile-master-v2`。
4. 每个端的夏、秋、冬都直接编辑该端的春季母版，不采用“春→夏→秋→冬”的连续重绘，避免累计漂移。
5. 每个季节的夜景直接编辑该季节的已验收白天图；不能拿春夜当夏夜的唯一参照。
6. 天气附着层、粒子素材最后生成，尺寸和风格来自已经锁定的母版。

每次调用明确标注输入：**图 1 = 编辑目标**；如需另一张图约束造型，标注 **图 2 = 结构参考**，不要把不同季节都称为同等风格参考。

母版图一旦换版，所有派生图重新验收。不允许用生成后未验收的图覆盖母版路径。提示词能减少漂移，不能代替参考图编辑和逐张验收。

将下方的“主体说明”替换为表中的一条完整描述，每次只生成一种素材。其他指令原样保留；输入已验收母版作为风格参考。

## 7. 验收与禁止事项

- [ ] 镜头正对小卖部，门面与画面平行，门框竖直、屋檐水平，没有侧墙主导或斜向透视。
- [ ] 与母版并排或半透明叠加检查：店铺边界、门窗、树根、主要树干、步道边缘未漂移。
- [ ] 非季节几何锚点偏移超过画布宽／高约 1%，或肉眼可见结构改变时修正；不靠裁切补救。树叶密度变化不作为树干漂移。
- [ ] 四季配色与植物变化明确，当前天气没有偷偷改变季节。
- [ ] 两层结构、开放售货窗、住宅二楼、高白墙黑铁栏藤蔓、粗老树干和砖地全部符合用户描述。
- [ ] 无生成文字、商标、水印；紧凑生活细节不遮住门窗，不要求大片天空留白。
- [ ] 透明层有真实 alpha，位置对齐，边缘没有白边；不能把截图里的棋盘格当透明。
- [ ] 在实际横幅、375px／768px／1440px、深浅主题下确认店铺与两侧绿化可辨认，标题清晰。
- [ ] 停止所有动画后仍完整美观；底图没有烘焙飘落粒子。
- [ ] 所有运行时素材有清单与对应提示词，未验收素材不标记为 ready。

同版本禁止随机改招牌、门窗数量、树木数量、房屋风格、镜头透视或画风。不要并行盲生成整套图片，不依赖相同提示词／随机 seed 保证结构一致，不承诺生成器能像设计软件那样精确锁定图层和坐标。
