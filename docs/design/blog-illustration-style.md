# 博客配图：白底黑笔手绘

版本：1.0；确定日期：2026-10-16。

用户验收参考为 Orca 文章的 `cover.png`、`worktrees.png` 和 `workflow.png`，位置：`src/content/posts/orca-agent-workspace/images/`。本规范用于文章配图，不约束 wallpaper 壁纸素材，不改变站点主题或头像等界面素材。

## 视觉要求

- 纯白画布、黑色细笔／签字笔线条，轻微自然不规则，文字为清晰可读的手写风格。
- 使用少量框、箭头、简笔图标和留白表达关系；封面可以加入少量与主题有关的人物或物件。
- 不使用彩色、霓虹、渐变、阴影、立体效果、灰色底、纸张纹理和无关装饰。不以颜色区分语义，改用标签、编号或虚实线。
- 封面优先横向构图，主要标题短而明确，重要内容避开边缘；正文图依据内容选择横向或纵向，复杂图分组或拆图。
- 深浅主题使用同一白底图，不能通过反色滤镜改变笔画和背景。

## 内容与核验

先阅读图周围的正文和原素材，再决定重绘内容。必须保留核心信息、关系与必要限定，纠正图中文字乱码和明显错误编号；不得编造产品界面、测量值或个人经历。代码标识、协议字段与序列号必须逐项检查。

流程图核对分支与汇合，时序图核对参与者、时间顺序、请求和返回方向，数据结构图核对节点和队列／栈状态。复杂图不以密集小字代替清楚的解释。

图的主要知识点应同时存在于正文、代码、表格或替代文本中。真实截图改绘后标注“示意／非截图”，保留原始证据，不把生成图作为运行结果。外部素材需要记录出处与适用授权，生成图不能照搬水印或冒充官方图。

## 生成与存放

默认使用内置 imagegen。重绘以原图作内容参考、Orca 图作风格参考；对含有错误的原图，以文章中的正确语义和明确提示词为准。每张最终图片单独生成、查看并核验。

图片保存在相应文章的 `images/` 内。已有素材另存为 `*-handdrawn.png`，更新 Markdown 和 frontmatter 引用；原图保留，不递归删除。生成记录存放在 `docs/design/`，不要将说明 Markdown 放进文章集合。

通用提示词基底：

> 纯白背景，黑色签字笔的简略手写手绘图。线条轻微自然不规则，清晰手写标签，结构疏朗、留白充足。只用黑白，不使用彩色、渐变、灰底、阴影、纸纹、霓虹和复杂装饰。用明确箭头、标签和编号表达逻辑，文字准确可读。保留指定的技术关系和代码标识，不新增未提供的事实。不添加水印或品牌标识。
