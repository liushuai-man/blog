# 执行计划一：wallpaper 壁纸镶嵌

更新：2026-10-16。状态：替代原四季微动画场景计划；已确定以动态壁纸为主、尽可能兼容，具体素材与接入方式待验证，运行时尚未改动。

## 目标与范围

将 wallpaper 壁纸嵌入博客现有背景区域，**大部分素材为动态壁纸，按不同格式尽可能兼容**。保留阅读优先的布局、主题设置和 `/blog/` 子路径部署。不再推进固定小卖部四季素材生成、季节／天气控制、tsParticles 或 Lottie 场景方案。

本次仅调整计划和相关说明。已有场景提示词与预览素材作为历史资料保留，不作为 wallpaper 的素材验收要求。当前背景、轮播和樱花继续按现有配置运行，不因取消计划而提前删除。

## 接入前确认

- 收集有代表性的动态壁纸样例，识别视频、Web、场景工程等实际类型；不将需求简化为静态图片拼贴。
- 核实素材来源、作者、授权、可分发范围和实际格式，记录是否依赖桌面宿主或外部服务。
- 如采用 Wallpaper Engine 素材，先验证所选素材在普通浏览器和 GitHub Pages 中的运行条件；不预设所有壁纸均可直接嵌入。
- 确定首页、文章页的展示区域及深浅主题效果，再实施对应配置与渲染调整。

## 动态壁纸兼容策略

以下为待验证的支持目标，不代表当前已经支持。按素材类型选择适配器，共用展示、偏好与生命周期接口，避免将一种格式写死为唯一入口。

| 素材类型 | 计划接入方式 | 验证与降级 |
| --- | --- | --- |
| 视频壁纸 | 优先验证 MP4／WebM，通过原生 video 静音循环播放 | 验证实际编码、浏览器播放与自动播放限制；失败显示海报图，不阻塞正文 |
| Web 壁纸 | 对可独立运行的 HTML／CSS／JS 包验证隔离嵌入 | 检查相对资源、脚本、宿主 API、音频和输入依赖；按需配置最小 iframe 权限及暂停通信，无法可靠暂停时停止或卸载嵌入内容 |
| 动态图片 | 验证 GIF／APNG／动态 WebP 的加载与展示 | 对无法直接暂停的格式，在隐藏、离屏或减少动态效果时替换为静态帧并卸载动态资源 |
| Wallpaper Engine 场景工程及其他专用格式 | 先调查现有可用的浏览器运行方案与转换路径，再决定是否适配 | 逐项记录宿主依赖、授权与兼容缺口；无法直接运行时，验证经授权的视频导出或静态预览方案，不以更换后缀代替转换 |
| 静态图片 | 作为常规壁纸及所有动态类型的兜底 | 支持桌面／移动裁切与主题适配，动态加载失败后可继续阅读 |

- 优先支持可在普通浏览器直接运行的素材；特殊格式在样例验证后逐步扩展，不承诺未经验证的全格式兼容。
- 同一壁纸允许配置多个媒体源和静态海报，根据实际支持情况回退；缺少某格式支持不应导致整个背景失效。
- 尽量保留动态效果；低性能设备、减少动态效果偏好或运行失败时回退静态图。记录回退原因，避免悄悄将全部动态素材改成静态图片。
- 视频和 Web 壁纸默认静音，无用户操作不发声；如允许交互，提供明确入口与键盘操作，背景层默认不抢占正文输入。
- 不嵌入未经检查的脚本包；验证外部资源、可部署路径及隔离边界。构建与浏览不要求访客安装桌面软件。

## 执行顺序

1. **样例验证**：按兼容策略收集壁纸并确认授权，在普通浏览器验证可用格式、加载方式和静态兜底；输出格式支持矩阵、实测环境及尚不能支持的能力。
2. **接入展示**：将确认可用的壁纸嵌入现有背景区域，适配桌面／移动端、横幅／覆盖模式与主题；内部资源路径经过 `url()`。
3. **交互与生命周期**：按素材需要接入开关与偏好，保持装饰层不拦截正文操作。动态素材遵循减少动态效果偏好，隐藏或离屏暂停，Swup 往返不重复初始化，销毁时释放资源；无用户操作不发声。
4. **替换收尾**：仅清理实际被替换的入口、配置、类型、样式和说明；旧樱花及轮播是否调整由明确需求决定。同步更新 README 与组件／配置说明。

## 验收

- [ ] 已确定壁纸样例、来源、授权、格式和浏览器接入方式。
- [ ] 兼容矩阵覆盖视频、Web、动态图片和专用场景格式；逐项标记直接支持、转换后支持或暂不支持，并记录实际验证结果。
- [ ] 动态素材可播放与循环；不支持编码、自动播放被拒、嵌入失败或外部资源失效时均能降级。
- [ ] 首页和文章页文字清晰，壁纸不阻挡链接、搜索、主题或显示设置。
- [ ] 375px、768px、1440px 和深浅主题下无横向溢出或不合理裁切。
- [ ] 直接刷新、`/blog/` 子路径和 Swup 往返均正常，资源失败时仍有可阅读的静态兜底。
- [ ] 动态素材支持减少动态效果和隐藏／离屏暂停，无重复实例、监听、计时器或自动发声。
- [ ] 记录实际资源体积与加载影响，不使用虚构性能分数。
- [ ] 实现后运行 `pnpm check`、`pnpm build`，并按影响运行针对性测试及浏览器验收。

## 回退

所选素材无法在静态站点运行或授权不允许分发时，保留当前背景，另选经确认的可用素材。取消场景计划本身不触发运行时迁移或依赖安装。
