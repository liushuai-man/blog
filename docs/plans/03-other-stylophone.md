# 执行计划三：「其他」栏目与触笔电子琴

更新：2026-10-14。状态：待实施；旧音乐播放模块已清理。本计划替代原口琴方案及误写的黑白琴键电子琴方案。

## 目标与边界

新增独立「其他」栏目，第一项功能为 **Stylophone 风格的触笔电子琴**：通过虚拟金属触笔接触金属音片发声，按住并横向滑过音片演奏旋律。[Stylophone 官方产品说明](https://stylophone.com/product/stylophone-s-1/)展示了触笔点触与滑动金属表面的演奏方式，作为交互参考。

栏目名称使用「其他」，入口使用「触笔电子琴」，附注 Stylophone。后续加入节奏、打字或小游戏时通过注册组件接入，不修改全局 Layout，也不把所有工具打包进首页。当前栏目与乐器均未实现，无已发布路由需要迁移。

第一版采用单音电子合成音色，包含点触、滑奏、低／中／高音区切换、音量、静音、可选颤音及数字简谱试听与跟弹。视觉和交互借鉴触笔乐器，不宣称精确复刻某个硬件型号。第一版不做钢琴采样、和弦复音、歌曲搜索、录音导出、MIDI 设备接入或完整合成器参数面板。

## 视觉与页面结构

- 栏目页沿用 `card-base` 展示工具卡片，不展示尚未实现的占位功能。
- 乐器采用紧凑机身、金属音片、简洁扬声器网孔与少量控制按钮；用站点主题色点亮当前音片，支持深浅主题。机身形体简洁，避免过多霓虹与复杂材质纹理。
- 金属音片是主要演奏面：自然音与升降音可用长短、错位和刻度区分，不能呈现为可按压的钢琴黑白键。音片同时标注音名和辅助键盘映射。
- 桌面按住拖动时，虚拟触笔笔尖跟随接触位置；手机以手指或设备触笔模拟金属笔，反馈不能遮挡命中的音片。无需先拖动装饰笔才能演奏。
- 第一版使用 C4–C5 共 13 个半音音片；低／中／高音区对应整体偏移 -12／0／+12 半音。此音域是网页方案选择，不代表硬件规格。
- 手机优先保证音片宽度和高度，可拆成相邻两个音片窗口并提供切换按钮，不把整台乐器等比缩小到无法演奏；窗口切换先停音，滑奏只发生在当前窗口内。
- 音片高亮和触笔移动即时、轻量；`prefers-reduced-motion` 下取消装饰动画，保留演奏所需的位置与状态反馈。

## 第三方组件策略

| 能力 | 优先选型 | 自定义代码边界 |
| --- | --- | --- |
| 合成音色、包络、颤音、节拍调度 | [Tone.js](https://github.com/Tonejs/Tone.js)（MIT） | 封装单音启动、音高切换、释放、音量和 dispose，不重写音频调度器 |
| 音量／速度滑块、复杂选择器 | [Bits UI](https://github.com/huntabyte/bits-ui) | 按需采用；普通按钮复用现有组件，皮肤沿用站点变量 |
| 简谱校验 | [Zod](https://github.com/colinhacks/zod) | schema 与 TS 类型一致，只在实际需要时安装 |
| 图标 | 现有 Astro Icon／Iconify | 复用已有依赖 |

以上为候选，当前未安装 Tone.js、Bits UI 或 Zod。实施时核对所选版本的上游许可证、Svelte 5／Astro 6 兼容性、加载范围与构建包体变化，记录测量结果。Tone.js 只在客户端动态导入，控件库不进入无关页面。

音色以带蜂鸣感的电子合成音为目标，由 Tone.js 的振荡器、包络和可选颤音实现；听感需单独试听验收。第一版无需采样下载，不使用钢琴／电钢琴音色。金属音片与触笔使用 HTML／CSS 或 SVG，命中、位置反馈和输入映射属于必要适配。若使用外部图片或音频，另行记录来源与授权，不直接复制品牌标识或官网素材。

## 触笔、滑奏与输入

- 点击“开始演奏”解锁音频，初始化成功后才允许发声；失败可重试。首次加载、刷新、悬停和移动触笔均不自动发声。
- 在音片上按下，相当于金属笔接触音片，持续发出一个音；松开立即释放。按住并滑入相邻音片时切换音高，重复命中同一音片不重触发。
- 滑奏采用逐音片切换的离散音高，不按横向位置连续弯音。第一版不增加独立连续音高滑条。
- 命中按真实音片形状判断，不能只按横坐标平均分段。进入间隙或离开金属演奏面立即停音；仍按住且重新进入有效音片时恢复发声，松开后移动不再发声。
- 演奏面使用 pointer capture 保证移出后松开仍能释放。捕获后通过坐标重新命中音片，不依赖固定的事件 target；pointercancel 和 lostpointercapture 释放当前接触。
- 第一版仅一个演奏输入拥有声音。有效 pointer 按下后忽略其他 pointer 和音符快捷键，直到释放；键盘模式采用最后按下优先，松开后可恢复仍按住的前一音。切换到 pointer 前清空键盘持有状态，旧输入的迟到释放不能停止新输入。
- 电脑键盘辅助映射：`A S D F G H J K` 对应 C、D、E、F、G、A、B、上方 C；`W E T Y U` 对应 C♯、D♯、F♯、G♯、A♯。忽略重复 keydown；音片可聚焦并通过 Enter／Space 按住演奏。
- 低／中／高音区、手机窗口通过有标签的按钮选择。切换音区或窗口先释放声音和输入状态，不要求通过鼠标移动选择八度。
- 音片区演奏时限制触摸滚动，区域外仍能正常滚动。搜索框、textarea、contenteditable、选择器或滑块聚焦、输入法组合输入或使用修饰键时，不拦截演奏快捷键。
- 静音、失焦、标签隐藏、离屏、Swup 切页及 dispose 均清除输入状态与声音。恢复后等待新的按下，不恢复先前接触。

## 简谱与跟弹

第一版提供 3 段原创练习，每段标注来源与许可，展示数字音符、升降号、八度点和时值。试听提供播放、暂停、重来、速度与当前音片高亮；跟弹显示目标音并提示是否匹配，不做复杂评分。

自由演奏、试听、跟弹互斥，切换模式先清除声音与调度。跟弹为单旋律逐音匹配：点触或滑入目标音片均可推进，同一次接触停留不能重复通过多个同音事件，重复音需要离开后再接触。休止符仅展示，不要求按键。试听按完整节奏播放；暂停停音并清除高亮和调度，继续从记录的事件位置开始，重来回到首事件。

```ts
type ScoreEvent = {
  degree: 1 | 2 | 3 | 4 | 5 | 6 | 7 | null; // null 为休止
  accidental: -1 | 0 | 1;
  octave: -1 | 0 | 1;
  beats: number;
};
type Score = {
  id: string;
  title: string;
  tonicMidi: number; // 首版固定 60，即 C4
  bpm: number;
  events: ScoreEvent[];
  source: string;
  license: string;
};
```

校验 beats 为有限正数、bpm 为 40–240、events 非空、来源与许可非空；休止符不携带升降号或八度偏移。自然音偏移为 `[0, 2, 4, 5, 7, 9, 11]`，叠加升降号和八度偏移后生成 MIDI 音高，并检查可通过音区与音片组合演奏。首版练习限制在中音区 C4–C5，避免演奏中切换窗口或音区。时钟与绘制调度使用 Tone，不解析任意简谱文本，不接未授权流行曲或旧音乐 API。

## 生命周期与故障处理

浏览器 API 仅在客户端初始化。每个乐器实例拥有输入监听、音频节点、触笔反馈和试听调度，不将音频管理器放入全局 Layout。卸载清理监听、observer、timer、动画帧、调度与库实例。

音频解锁和动态导入检查实例是否仍有效，销毁后的异步完成不能创建资源或恢复播放。Swup 往返不重复绑定。pause 释放声音、输入和调度，dispose 进一步销毁资源；启动失败重试不累积实例。

Astro 预渲染说明与练习简谱，Svelte 增强演奏与高亮。关闭 JavaScript、无音频支持或库加载失败时，说明与简谱仍可阅读。音频不可用时禁用演奏并显示原因，不留下永久“加载中”。

## 执行阶段

1. **Shell 与注册**：创建「其他」栏目与触笔电子琴路由，接入导航、可配置启停、懒加载和失败提示。
2. **音片与触笔**：完成金属演奏面、形状命中、虚拟笔尖、手机窗口、主题和可访问标签，先验证无音频输入反馈。
3. **音频 adapter**：验证单音电子音色、音高切换、可选颤音、释放与销毁；试听验收并记录加载体积。
4. **输入 adapter**：接入点触、按住滑奏、键盘替代、音区按钮；处理间隙、移出、捕获丢失、输入所有权、失焦与 Swup 清理。
5. **简谱模式**：校验练习，接入试听、跟弹、速度与目标音片高亮，验证重复音规则。
6. **扩展验证**：用不含音频的最小演示工具检验注册与 Shell 接口，不为验证强行发布第二个功能。
7. **发布前检查**：完成视觉、音频、无障碍与资源验收；未经授权不推送或部署。
