# 执行计划四：像素画布

日期：2026-10-19。喵喵屋第二个独立玩具，沿用注册表、ToolPage 和懒加载 Shell；调色增强依赖见下文。

## 实现范围

- 画布为页面主体，网格铺满整个可用区域，不固定行列数；缩小增加可见方格、放大减少，以视野中心为锚点。手掌工具拖动视野，离屏画作保留。
- 图标工具栏和紧凑常用色，操作说明默认收起；展开调色面板选择颜色；左键点涂／拖动填色，右键点按／拖动擦除；触屏可切换画笔／橡皮擦。
- 快速滑动补齐经过的格子，一次按下到释放为一笔；最多撤回本次打开后的 100 笔，撤回历史不缓存。
- localStorage 独立 key `blog:pixel-canvas:v1`，150ms 防抖保存，松开、失焦、隐藏、切页和卸载立即尝试写入；失败提示导出备份。
- 透明 PNG 导出全部已绘制内容，按内容边界裁切、不含网格。整数倍像素缩放，超出浏览器合理图像容量时提示，不静默截断。
- 键盘方向键移动，空格／Enter 填色，Delete／Backspace 擦除，画格聚焦时 Ctrl／⌘ + Z 撤回。

## 验收

检查点击、快速滑动、右键擦除、缩放、撤回、刷新恢复、缓存损坏／存储不可用和 PNG。检查 375px／768px／1440px、深浅主题、子路径刷新与 Swup 往返；真机触屏单独验证。

运行 `pnpm test:pixel-canvas`（插值、撤回、历史上限、透明色恢复和无效缓存）、`pnpm test:other`、`pnpm test:stylophone`、`pnpm check` 和 `pnpm build`。

缓存只保存当前浏览器当前站点的一幅画，不提供跨设备同步。关闭 `otherConfig.pixelCanvas` 可停用入口。封面见 [素材记录](../design/other-module-covers.md)。

- 类型检查 0 errors／0 warnings，仅既有 SakuraEffect 的 1 条 hint；生产构建生成 47 页，Pagefind 索引 35 篇文章。因本机 Volta／pnpm 启动异常，使用已安装 Node 直接执行 package.json 中相同脚本入口，未重新安装依赖或修改锁文件。

## 画布主体与自由网格调整

- 按用户最新要求移除大标题、编号和常驻说明，使用紧凑图标工具栏，说明通过问号展开；图标保留中文可访问标签和悬停提示。复用现有 Icon 组件与 Iconify 图标，无新增依赖。
- 画布铺满工具区域，模型改用稀疏坐标存储，不限制 32×32 行列；缩小增加可见格子、放大减少，以中心为锚点，手掌拖动视野。旧版缓存自动迁移，画作与视野位置／缩放一并缓存，离屏格子不丢失，导出全部非空格子包围范围。
- 工具页增加可选紧凑模式，仅画布页启用。通过当前工作区标记限制样式：收起大横幅、复位主网格位移，避免樱花覆盖绘图区；Swup 返回其他页面时恢复原样，不修改背景配置和全局布局运行时。
- 新模型 7 项、模块 3 项、电子琴 6 项测试通过；覆盖中心缩放、负坐标、迁移、撤回和导出边界。类型检查 0 errors／0 warnings，保留原有樱花 hint。
- 浏览器查看 375px、768px、1440px 与深浅主题，无页面横向溢出；验证拖绘、视野移动、缩放、键盘、撤回、刷新和 Swup 往返。实际导出的 11 格横向笔画解码为 176×16 RGBA PNG。
- 真机触屏、存储故障及长期性能仍待验证；导出受浏览器图像容量限制，过大时提示，不静默裁掉内容。

## 调色增强（2026-10-22）

- 保留工具栏的 8 个快捷色，新增可展开面板：48 种预设色、色相与饱和度／明度调节、6 位 HEX 输入和本次打开期间最多 16 个最近实际用色。选择颜色后自动切回画笔；最近用色不跨刷新缓存。画作缓存与透明 PNG 格式保持兼容。
- 接入 [vanilla-colorful](https://github.com/web-padawan/vanilla-colorful) 0.7.2，MIT 许可、无运行依赖，使用标准 Custom Elements 与 Shadow DOM；通过 Svelte 5 的客户端生命周期接入，Astro SSR 不执行注册代码。只在调色面板打开时动态导入，关闭时移除实例与事件监听，异步导入完成后检查组件是否已销毁。加载失败仍保留预设色、HEX 与系统选色。
- 本次生产构建中，调色器独立 JS 文件为 6,166 字节，gzip 为 2,830 字节；该数字仅为调色器文件，不包含 Svelte 面板与站点共享代码。首页和文章不导入此模块。
- 10 项像素画布／模块回归测试通过；类型检查 0 errors／0 warnings，仅既有樱花 hint；静态构建 47 页、Pagefind 索引 35 页。由于本机 Volta 启动异常及现有 node_modules 使用 pnpm 11 元数据，依赖清单与锁文件使用 pnpm 9.14.4 生成，验证直接执行 package.json 对应的 Node 入口。
- 浏览器检查 375px／768px／1440px 和深浅主题，页面无横向溢出；验证 HEX 选色落笔、无效 HEX 禁止应用、键盘调色、最近用色、撤回、子路径刷新与 Swup 往返后重新打开调色器；控制台未见 warning／error。真机触屏、加载失败的浏览器注入测试与长期性能未验证。
